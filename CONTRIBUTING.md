# Contributing

Thank you for contributing to the Hashe Elementor ACF Editor.

Before submitting a change, open an issue describing the problem, the Elementor and ACF versions, the field type, and reproduction steps.

Use a feature branch and open a pull request. Run the PHP and JavaScript checks in the GitHub Actions CI workflow. Include automated regression tests when changing permissions, field matching, saving, or editor initialization.

Test in an isolated WordPress staging instance before claiming browser compatibility.

Do not submit customer site data, login credentials, licensed plugin binaries, third-party screenshots without permission, or proprietary ACF Pro code.
